# Archimaid

This application is a data collection tool to assist in functional, application and technical architecture analysis.
It must respect principles of DDD and hexagonal architecture. Most of the work is a CRUD on the domane aggregates classes.

# Implementation:
- light backend implementation with python fastAPI + PostgreSQL database
- Light frontend implementation, should not be required. 

# Domain definition
Domain desciption is provided as a plantuml diagram : domain.puml

The "Team" is a project team implementing the "Application". As architects, we need to gather their requirements and/or the existing technological stack to design the future stack.
